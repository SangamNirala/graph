

## 🎯 **HOW TO GET REAL DATASETS**

### **Step 1: Register for Free APIs**
```bash
# USDA Food Data Central
curl "https://api.nal.usda.gov/fdc/v1/foods/search?query=apple&api_key=YOUR_KEY"

# Open Food Facts
curl "https://world.openfoodfacts.org/api/v0/product/3017620422003.json"

# Spoonacular
curl "https://api.spoonacular.com/recipes/complexSearch?query=pasta&apiKey=YOUR_KEY"
```

### **Step 2: Download Bulk Data**
```python
# Example: Download USDA database
import requests
import pandas as pd

# Food Data Central bulk download
url = "https://fdc.nal.usda.gov/fdc-datasets/FoodData_Central_csv_2023-10-26.zip"
response = requests.get(url)

# Open Food Facts export
openfood_url = "https://static.openfoodfacts.org/data/en.openfoodfacts.org.products.csv"
df = pd.read_csv(openfood_url, sep='\t', low_memory=False)
```
